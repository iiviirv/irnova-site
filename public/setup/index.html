در دسترس

نصب یا به‌روزرسانی با تلگرام

ربات رسمی شما را مرحله‌به‌مرحله راهنمایی می‌کند. برای به‌روزرسانی پنل موجود نیز از همین مسیر استفاده کنید.

نصب پنل جدید به‌روزرسانی پنل موجود
  1. نام کاربری ربات را دقیقاً بررسی کنید: @IRNovaProxy_Bot.
  2. برای نصب، گزینه Install و برای پنل موجود، گزینه Update را بزنید.
  3. بعد از پایان کار، آدرس Worker خودتان را باز کنید.
پیشنهادشده

نصب مستقیم با Cloudflare

مسیر رسمی Cloudflare، کد را از مخزن عمومی Nova می‌گیرد و Worker، فضای KV و دیتابیس D1 را داخل حساب خودتان می‌سازد.

Deploy to Cloudflare
  1. هیچ توکنی در سایت Nova وارد نخواهید کرد.
  2. Cloudflare ورود و ساخت منابع را در دامنه خودش انجام می‌دهد.
  3. پس از نصب، در آدرس Worker رمز مدیریت را تعیین می‌کنید.
Available now

Secure Nova setup

Nova is installed in your own free Cloudflare account. This page never asks for your Cloudflare password or API token.

Deploy directly with Cloudflare Install with the Nova bot Update an existing panel
  1. For direct deployment, confirm the browser is on deploy.workers.cloudflare.com.
  2. If you use Telegram, confirm the exact username: @IRNovaProxy_Bot.
  3. When complete, open your Worker URL and finish the on-Worker setup.

چطور مطمئن شویم؟ / Safety check

هشدار: اگر هر صفحه‌ای در novaproxy.online از شما رمز Cloudflare یا API Token خواست، آن صفحه را ببندید و گزارش کنید.

Warning: Close and report any novaproxy.online page that asks for a Cloudflare password or API token. Official Cloudflare authorization pages use dash.cloudflare.com or deploy.workers.cloudflare.com.
